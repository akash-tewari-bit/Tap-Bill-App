- **Printing:** After creating an order, a receipt should be printed. The receipt must contain the business logo, name, address, phone, order details, total, and payment mode.
- **Reports:** Display orders in a table for a selected date range, with an option to export as a CSV file.
- **Settings:** Manage business information (logo, name, etc.) and menu items.
- **Branding:** The app should be named Tap-Bill and use the provided logo.
- **Data Persistence:** Use local storage for app data and MongoDB for user profiles and authentication.
- **Access Control:** Only active users or super admins should be able to use the app. Inactive users should be logged out automatically.
